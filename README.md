# Просмотр G-кода

Просмотрщик управляющих программ ЧПУ (.tap, .nc, .cnc, .ngc, .gcode …): 3D-траектории, симуляция, проверка, калькулятор режимов.

Открыть: https://alecsonder.github.io/gcode-viewer/ — в Chrome на Android «Установить приложение» / «Добавить на главный экран», в Chrome/Edge на Windows — значок установки в адресной строке.
